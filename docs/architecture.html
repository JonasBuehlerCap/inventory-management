Factory Inventory Management System

Architecture overview: a Vue 3 single-page app backed by a FastAPI service over in-memory JSON data.

Summary

A demo full-stack application for monitoring factory inventory, orders, demand, backlog and spending. The browser loads a Vue 3 SPA (port 3000) that calls a FastAPI REST service (port 8001) through a single client module. The API holds no database: all JSON files in server/data/ are loaded into memory at startup, filtered per request, validated by Pydantic and returned to the client.

Roughly 5,900 lines across client and server; 6 routed views, 8 components, 3 composables, English and Japanese locales, and a pytest suite for the backend.

Data flow

Request path

  1. User changes a filter in FilterBar (period, warehouse, category, status).
  2. useFilters holds the state as a shared singleton; views read it via getCurrentFilters().
  3. A view calls a method in api.js, which builds query params and omits any filter set to all.
  4. FastAPI handler applies apply_filters and filter_by_month to the in-memory lists.
  5. The result is validated by the Pydantic response_model and returned as JSON.
  6. The view stores raw data in refs and derives displayed values in computed properties.

Month accepts YYYY-MM or a quarter key such as Q3-2025. Inventory has no time dimension, so month does not apply to it.

Observations

  • The client calls /api/tasks and /api/purchase-orders, but no such routes exist in server/main.py. The Pydantic models PurchaseOrder and CreatePurchaseOrderRequest are defined, so the endpoints appear unfinished.
  • views/Backlog.vue exists but is not registered in the router; backlog is shown through a modal on the Dashboard.
  • The API base URL is hardcoded to http://localhost:8001/api in api.js, and CORS allows all origins. Both are acceptable for a demo but need changing for any deployment.
  • The data store is read-only in-memory: any write feature would not persist across restarts.
  • Quarter mapping and quarterly reports are hardcoded to 2025.
